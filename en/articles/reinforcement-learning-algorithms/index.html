Reinforcement Learning Algorithms

📅 June 14, 2026 • ⏱️ 4 min read
🏷️ Tags: Reinforcement Learning

Reinforcement Learning (RL) is the field dedicated to teaching agents how to behave in an environment to maximize cumulative reward. While the overall goal—making an agent act optimally — seems simple, the algorithms required to achieve it are deeply complex.

Foundational Conceptual Axes

To understand how a powerful algorithm like DQN or SARSA works, we must first understand the three foundational conceptual axes that define the field:

  • Goal (Prediction vs. Control)
  • Data Source (On-Policy vs. Off-Policy), and
  • Computational Engine (Monte Carlo vs. Temporal Difference).

I. The Goal: Prediction vs. Control

This axis asks: Are we assessing value, or are we optimizing action?

Prediction (The Value Game)

The goal of prediction is to calculate Value Functions ($V$ or $Q$). An agent that predicts simply answers the question, “If I follow this current set of rules, what is the expected return?” It is passive and descriptive, giving a numerical score to a state.

Control (The Policy Game)

The goal of control is to find the Optimal Policy ($\pi^*$). This agent does not just report a number; it identifies the best possible set of rules, answering, “What must I do next to guarantee the maximum possible reward?” It is active and prescriptive.

The Relationship: Prediction informs Control. Control uses the predicted values to continuously select the action that maximizes the return.

II. The Data Source: On-Policy vs. Off-Policy

This axis addresses the crucial question of data reliability and dictates the algorithm’s practical performance.

On-Policy Learning (The Method of Direct Practice)

In an on-policy setting, the agent learns by using the data generated by the policy it is currently trying to improve. It learns directly from its own experience.

  • Analogy: A student studying for a test only practices with the specific textbook they are currently reading.
  • Trade-Off: This method is highly stable because the data source matches the goal, but it is severely data-inefficient; if the agent performs poorly early on, it must suffer through poor performance millions of times to learn.

Off-Policy Learning (The Power of Observation)

Off-policy methods are revolutionary because they decouple the action generator from the learning process. They allow the agent to learn about a perfect, optimal policy ($\pi^*$) using data collected by a completely different policy ($\mu$), such as a random walk, or an expert human.

  • Analogy: A student (Agent $\pi^*$) learns about history not from their own notes, but from the curated textbooks and lectures of a seasoned historian ($\mu$).
  • Trade-Off: This grants unparalleled sample efficiency and flexibility, but it introduces profound mathematical risks, requiring sophisticated tools like Importance Sampling to correct for the data mismatch.

III. The Engine: Monte Carlo vs. Temporal Difference

This axis determines how the agent calculates the value of a state.

Monte Carlo (MC): The Average Approach

MC methods are root in statistics. They estimate the value by running complete simulations (episodes) from start to finish and then averaging the total cumulative reward received. They wait for the final result before making an estimate.

Limitation: Requires that episodes must eventually terminate (they must end).

Temporal Difference (TD): The Step-by-Step Approach

TD methods are computationally efficient. Instead of waiting for the end of an episode, they update their estimate after every single time step. They learn by bootstrapping—using the value they just estimated for the current state ($S$) to predict the value of the next state ($S’$).

Advantage: TD methods are far more robust for continuous tasks because they never have to wait for the end of an episode.

IV. Algorithms in Practice: Synthesis of Concepts

The modern algorithms are defined by where they fall on this four-axis map.

Algorithm Classification Concept Summary Role
MC Control MC, Control, On-Policy Uses full episode averages (MC) to find the optimal rules (Control). A foundational approach limited by termination and variance.
SARSA TD, Control, On-Policy Learns the optimal policy by trusting its current, real-time actions. The Safety Controller. Ideal for environments where actions have real consequences.
Q-Learning TD, Control, Off-Policy The pinnacle of off-policy learning. It uses the $\max$ operator to assume perfection, even if the data is suboptimal. The Dream Planner. Excellent for maximizing returns using limited, diverse data.
DQN (Deep Q-Networks) TD, Control, Off-Policy Uses deep neural networks to solve Q-Learning in complex, high-dimensional spaces. The industry standard for powerful, sample-efficient control.
Actor-Critic (A2C/A3C) TD, Control, Mostly On-Policy Separates the policy (Actor) from the value evaluation (Critic). Excellent for continuous control, offering stability while improving policy.

Conclusion: The Landscape of Choice

No single algorithm is perfect. The choice of method must be dictated by the problem’s nature:

  • If the environment is critical (e.g., autonomous vehicle), safety dictates an On-Policy method like SARSA.
  • If data is scarce or precious (e.g., real-world robotics), efficiency dictates an Off-Policy method like DQN or Q-Learning.
  • If the environment is complex and continuous, stability and scalability demand a TD-based Actor-Critic architecture.

By understanding that these algorithms are merely different tactical combinations of prediction, control, simulation, and data sourcing, we gain a profound appreciation for the theoretical elegance and practical complexity of modern Reinforcement Learning.
