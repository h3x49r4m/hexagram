Linear Decay Function

📅 August 12, 2026 • ⏱️ 5 min read
🏷️ Tags: Functions Decay Time Series

In the world of data, time is rarely linear. When analyzing trends—be they stock prices, environmental measurements, or user engagement—the assumption that yesterday’s data is equally important as today’s data is often flawed. Human behavior, physical systems, and market forces tend to be highly responsive to recent changes.

To address this, sophisticated analysis techniques move beyond simple averaging, favoring methods that assign greater influence to the most recent observations. Among these, the Linear Decay Function (often implemented as a specific type of Weighted Moving Average, or WMA) is a powerful tool for capturing recency and responsiveness in time series data.

What is the Concept of Decay in Time Series?

When we calculate a simple average (a Simple Moving Average, or SMA), every data point within the chosen window is treated as having equal importance.

Example: If we average [6, 8, 10], the SMA is $(6+8+10)/3 = 8$.

However, real-world intuition tells us that the value $10$ is more indicative of the current trend than the value $6$ recorded earlier. The Linear Decay Function formalizes this intuition by giving the most recent data points the largest weights.

A “linear decay” model assumes that the influence of a data point decreases linearly as it moves further back in time.

The Mechanics of Linear Decay

The Linear Decay Function calculates a weighted average where the weights correspond to the position of the data point within the specified lookback window.

If we define a lookback window size $k$ and the time series data as $x$, the weights applied will be $\{1, 2, 3, \dots, k\}$.

The Formula

For a given time step $t$, the decayed value $Y_t$ based on a window size $k$ is calculated as:

$$ Y_t = \frac{\sum_{i=0}^{k-1} (x_{t-i} \cdot (i+1))}{\sum_{j=1}^{k} j} $$

Where:

  • $x_{t-i}$ is the data point $i$ steps back in time.
  • $(i+1)$ is the weight assigned to that data point (the weight increases as $i$ approaches 0, meaning the weight increases as the data point approaches $t$).
  • The denominator ($\sum_{j=1}^{k} j$) is simply the sum of the weights (e.g., if $k=3$, the denominator is $1+2+3=6$).

Step-by-Step Example Walkthrough

Let’s apply this process using the provided example:

  • Time Series $x$: $[2, 4, 6, 8, 10]$
  • Window Size $k$: $3$
  • Target Calculation: Estimating the trend based on $6, 8, 10$.

Step 1: Identify the values and weights. The three values are:

  • $x_{t-2} = 6$ (2 steps back, assigned weight 1)
  • $x_{t-1} = 8$ (1 step back, assigned weight 2)
  • $x_{t} = 10$ (0 steps back, assigned weight 3)

Step 2: Calculate the weighted sum (the numerator). The numerator is the sum of (Value $\times$ Weight):

$$\text{Numerator} = (6 \cdot 1) + (8 \cdot 2) + (10 \cdot 3)$$

$$\text{Numerator} = 6 + 16 + 30$$

$$\text{Numerator} = 52$$

Step 3: Calculate the sum of weights (the denominator).

$$\text{Denominator} = 1 + 2 + 3 = 6$$

Step 4: Calculate the final result.

$$Y_{\text{last}} = 52 / 6 \approx 8.67$$

Comparison of Results

Method Calculation Result Interpretation
Simple Moving Average (SMA) $(6 + 8 + 10) / 3$ $8.00$ Treats all points equally.
Linear Decay Function (WMA) $(6\cdot 1 + 8\cdot 2 + 10\cdot 3) / 6$ $8.67$ Weights the most recent data highly.

The $8.67$ value is significantly closer to the most recent data point ($10$) than the $8.00$ value. This confirms that the Linear Decay Function effectively assigns greater predictive weight to current trends.

Practical Implications and Applications

The ability to give higher weight to recent observations makes this technique valuable across numerous data domains:

1. Financial Forecasting (Stock Prices)

In trading, momentum is key. A large spike in stock price today suggests strong immediate buying interest. Using an SMA might dilute this spike with historical data, leading to an underestimation of the current trend. A linear decay function ensures that the most recent trading volume and price movements dominate the forecast, improving responsiveness.

2. Industrial IoT and Sensor Data

If a machine sensor suddenly shows an abnormal temperature spike, you want the immediate reading to flag the alert, not to average it out with the stable readings from the last hour. Linear decay provides a highly sensitive, rapidly adjusting trend line.

3. Web Analytics and Behavioral Tracking

When modeling user engagement (e.g., click-through rates or average session duration), a sudden increase in activity suggests a successful new feature. By weighting recent data highly, the model quickly adapts and recognizes the change, unlike an SMA, which would take longer to react.

Caveats and Limitations

While highly useful, the Linear Decay Function is not a universal solution and comes with specific assumptions:

  1. Assumes Linear Weighting: This function assumes that the drop-off in influence is precisely linear. If the underlying data process follows an exponential decay (where the decline is steeper initially and flattens out), an Exponential Moving Average (EMA) might be a more accurate model.
  2. Lag and Noise: The resulting value is a smoothing mechanism, not a predictive one. It is an estimate of the current underlying trend. If the raw data is extremely noisy, even a weighted average might struggle to differentiate between signal and random fluctuation.
  3. Window Size ($k$) is Critical: Choosing the wrong window size is the most common mistake. A very small $k$ makes the forecast too sensitive to noise (overfitting). A very large $k$ makes it slow to react (lagging).

Conclusion

The Linear Decay Function is a foundational technique in time series analysis that elegantly addresses the human tendency to value what is current. By systematically assigning weights that increase with recency, it provides a more responsive and contextually accurate view of trends than simple averaging. Understanding this concept allows data practitioners to move beyond static models and build forecasting tools that are genuinely aware of the passage of time.
